Agent with tools

A skail function runs a support agent in a loop: at each step the model decides to use a tool (look up the order, track the delivery) or to answer the customer. Each decision and each tool call is a recorded step, so if the worker stops, the case resumes without asking the model again. With no answer in 6 steps, the case goes to a person.
