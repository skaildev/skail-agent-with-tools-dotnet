Agent with tools

A skail function runs a customer support agent in a loop: at each step a model decides to use a tool (look up an order, track a delivery) or to answer. Each decision and each tool call is a recorded step, so when the app stops in the middle of a case, the case goes on without asking the model again. With no answer in 6 steps, the case goes to a person.
